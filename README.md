 
# Narrador de Histórias com IA 🎙️🤖

Este projeto implementa um narrador de histórias interativo que combina gravação de áudio, transcrição de fala e inteligência artificial para criar experiências criativas e envolventes.

## 🚀 Funcionalidades
- 🎙️ Gravação de áudio pelo microfone
- 📝 Transcrição de fala com Whisper
- ✨ Continuação da narrativa com GPT
- 🔊 Narração em voz com gTTS

## 🛠️ Tecnologias utilizadas
- Python
- Whisper (Speech-to-Text)
- GPT (geração de texto)
- gTTS (Text-to-Speech)
